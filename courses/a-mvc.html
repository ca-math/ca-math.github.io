P1.
\( A = (4,-2,7), B = (-2,0,3), C = (7,-3,9) \)

The three points are collinear. If you label the points as A, B, C, find:
\( \vec{AB} = -2 <3,-1,2>, \vec{BC} = 3 <3,-1,2> \)
This means point B goes to point C following the same direction as that from point A to B, since the vectors are multiples of each other with the tip of the first coinciding with the tail of the second.

P2.
\( A = (2,9,1), B = (3,11,4), C = (0,10,2), D = (1,12, 5) \)

Compute the vectors directly to confirm that are equal in pairs:
\( \vec{AB} = < 1, 2, 3> = \vec{CD} \)
\( \vec{BD} = < -2, 1, 1> = \vec{AC} \)
Therefore, the points form a parallelogram.
